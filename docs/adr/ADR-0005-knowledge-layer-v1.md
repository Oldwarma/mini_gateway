# ADR-0005: 知识层 v1 采用轻量导入（非完整离线管线）

- 状态: 提议
- 日期: 2026-08-18
- 决策者: joema
- 涉及 spec: 无（架构层）
- 关联 ADR: [ADR-0001](ADR-0001-tech-stack.md)

## 背景 / 上下文

论文的离线知识管线较重：来源发现 → 抓取 → 原子化拆解 → 实体识别 → 四重检查 → 背书声明。对 v1（验证运行时 Harness 闭环）而言，完整管线会显著推迟价值验证。

## 决策

v1 知识层用**轻量导入器**（`knowledge/ingest.py`）：

- 从 JSON / YAML 文件导入已整理好的 claims / evidence / sources；
- 数据结构与论文一致（sources 清单、evidence 证据记录、claims 背书声明），保留"来源锚定"语义；
- 导入时对每条 claim 做最小校验（必须有来源引用、归属已注册实体）——即论文"promotion gate"的轻量版；
- 完整离线管线（自动抓取、LLM 抽取、人工审核流）留作 v2。

## 后果

**正面：**
- 快速起步，运行时闭环先行，尽早验证 Harness 价值
- 数据结构与论文对齐，后续补管线无需重构

**负面：**
- 知识获取依赖手工整理示例数据
- 真实场景下知识新鲜度需人工维护

## 替代方案

- **v1 就做完整离线管线** —— 否决：工作量过大，应先验证运行时闭环；管线是增强项不是必要项。
